# Guía de reservas

## 1. Preparar la cuenta

Abre la configuración y elige tu cola de trabajos. Ten a mano la ficha del cliente.

## 2. Crear una reserva

Elige la hora, comprueba la dirección y guarda la cita. Antes de terminar, lee cómo [confirmar los datos](#3-confirmar-los-datos).

## 3. Confirmar los datos

Comprueba la fecha y el teléfono. Si necesitas cambiar algo, consulta el apartado 4.

## 4. Cambiar una reserva

Abre la reserva guardada, elige otra hora disponible y confirma el cambio.
